# Ontologies for Imaging Data

This directory hosts the LaTeX source code for the presentation to be given at
the "Image Data Community Days" in April 2026.


## Copying

The contents of this directory are released under the terms of the
Creative Commons Attribution-ShareAlike 4.0 International License.


## Building

Run `make all` to build the presentation.

Pre-requisites:

* A TeX distribution (tested with [TexLive 2025](https://tug.org/texlive/))
* [Inkscape](https://inkscape.org)
